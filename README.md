Hugging Face Flashcard Generator

A beginner-friendly Python project that generates study flashcards using the Hugging Face Inference API.

Features

- Takes a topic as user input
- Generates 5 study flashcards
- Provides questions and short answers
- Measures response time

Technologies Used

- Python
- Hugging Face Inference API
- Hugging Face Hub Python Library
- Groq inference provider

Setup

1. Install Python.
2. Install dependencies:
   "pip install -r requirements.txt"
3. Set your Hugging Face token as the "HF_TOKEN" environment variable.
4. Run the application:
   "python app.py"

Note: Never share or upload your Hugging Face token.
